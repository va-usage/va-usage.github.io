# Knowledge base schema

The knowledge base connects three perspectives on documented visual analytics usage.

- **System specification:** interface views and subviews, their capabilities, coordination, and system context.
- **Intended workflow:** stages with local goals, intended activities, expected outcomes, linked functionality, and directed transitions.
- **Documented case:** case context and analytical episodes. Strategy is recorded at episode level; steps retain intent, operations, documented outcomes, and evidence.

Workflows and cases are extracted independently from their respective evidence and reference the same system specification. Workflow stages and case episodes retain independent boundaries; candidate correspondences are an analytical product rather than an extraction dependency.
